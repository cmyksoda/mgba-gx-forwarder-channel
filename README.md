## Install

0. **Install BootMii and/or Priiloader first.** I took time to make sure that this `.wad` is safe, but one should always have protections in place in case of a banner brick.
1. Download the compiled `.wad` on the releases page.
2. Install using the WAD manager of your choice.
3. Ensure you've downloaded mGBA-GX, and it is in `apps/mGBAGX/boot.dol, on SD or USB — that exact folder name`

## Uninstall

- Use the WAD manager you used to install the channel to uninstall it, or, delete it from the Wii system settings.
